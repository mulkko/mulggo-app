API 엔드포인트 목록

실시간·정확한 스펙은 백엔드 켠 상태에서 http://127.0.0.1:8000/docs에서 확인하세요.
이 문서는 서버 안 켠 상태에서 빠르게 참고하거나, 외부에서 프롬프트 작성할 때 붙여넣기용입니다.
엔드포인트가 추가/변경되면 이 파일도 같이 업데이트해야 합니다 (자동 동기화 안 됨).

auth — backend/api/auth.py (prefix: /api/auth)

POST/api/auth/login

일반 회원 로그인. 로직: backend/auth/login.py

request (JSON)email, password
response{success, data:{user_id, email, name}, error:{message, code}}

POST/api/auth/admin-login

관리자 로그인 (is_admin 서버 검증 포함, 403 가능).

request (JSON)email, password
response{success, data:{user_id, email, name}, error:{message, code}}

POST/api/auth/signup

회원가입. 로직: backend/auth/signup.py. 사업자등록증은 선택 — 첨부해도 회원가입 성공엔 영향 없고 저장은 백그라운드 처리.

request (multipart/form-data)email, name, password, password_confirm, agree_terms, agree_privacy, biz_cert_file(선택), biz_cert_data(선택, /biz-cert-ocr로 확인·수정한 확정값 JSON 문자열 — 있으면 재OCR 안 함)
response{success, data:{user_id, email, name}, error:{message, code}}
note"전체 동의"는 서버로 안 보냄(프론트 편의). 비밀번호는 영문·숫자·특수문자 포함 8자 이상 서버 검증.

POST/api/auth/biz-cert-ocr

회원가입용 사업자등록증 OCR 미리보기. DB/디스크 저장 안 함 — 사용자가 확인·수정 후 /api/auth/signup에 biz_cert_file+biz_cert_data로 함께 제출. 로직: backend/auth/signup.py.

request (multipart/form-data)file (jpg/jpeg/png/pdf, 최대 10MB)
response{ocr_success, extracted:{company_name, ceo_name, biz_no, corp_no, open_date, birth_date, business_address, entity_type}, error, error_type, error_label}

admin — backend/api/admin.py (prefix: /admin)

GET/admin/bizinfo-count

기업마당 총 공고 건수 조회 (1페이지만 요청, 가벼움).

response{count}

POST/admin/bizinfo-crawl

기업마당 전체 수동 크롤링 + DB 저장. 실행 결과는 crawl_batch_logs에 기록됨.

response{success:true, data:{fetched, inserted}} 또는 {success:false, error:{message, code}}

GET/admin/batch-logs

최근 배치 실행 로그 5건 조회.

response{success, data:{logs:[{source, fetched_count, inserted_count, status, ran_at}]}}

GET/admin/members

관리자 회원 목록 + 통계.

response{success, data:{members:[{user_id, name, email, created_at, applicant_type, last_login_at, status}], stats:{total, new_today, active_30d}}}

test — backend/api/test_ocr.py (prefix: /api/test)

테스트 전용. 정식 회원가입 플로우와 무관, DB 저장 안 하고 CSV로만 남김.

POST/api/test/ocr-upload

사업자등록증 OCR 파싱 테스트용.

request (multipart/form-data)file
response{file_name, ocr_success, csv_saved, extracted, error, error_type, error_label}
