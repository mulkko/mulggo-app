mulkko 서버 링크 (팀 공유용)

dev_links.html의 localhost/127.0.0.1 주소를 서버 PC의 LAN IP(192.168.0.160)로 바꾼 버전입니다. 서버 PC가 켜져 있고 같은 네트워크(기기 간 통신 허용되는 네트워크)일 때만 접속됩니다.

"백엔드 연동일"은 해당 화면이 실제 백엔드 API까지 연결되어 동작하는 화면일 때만 채웁니다(마지막으로 그 연동 코드가 수정된 날짜). 비어있으면 아직 UI만 있거나 목업 데이터로 동작하는 화면입니다.

"구현율"은 자동 계산이 안 돼서 직접 입력하는 칸입니다(예: "70%"). 화면마다 "다 됐다"의 기준이 달라서 코드량이나 커밋 수로 추측할 수 없어 수동으로 채웁니다. 비어있으면 아직 입력 전이라는 뜻입니다.
