사용자 화면 새 페이지 요청 체크리스트

외부에서 프롬프트 검증받고 가져올 때, 아래 항목을 채워서 같이 주면 됩니다.
(외부 검증 도구는 이 저장소 코드에 접근 못하니, 특히 파일 경로는 정확히 적어주세요.)

1. 기술 스택

  • React + Vite + TypeScript, CSS Modules
  • 컴포넌트 파일: PascalCase (Xxx.tsx), 짝꿍 CSS는 소문자 시작 camelCase (xxx.module.css)

2. 타겟 환경

  • 모바일 우선 레이아웃
  • 데스크톱에선 frontend/src/styles/common.css의 .pageContainer 클래스로 최대 640px 가운데 정렬
  • 별도 데스크톱 전용 레이아웃(사이드바, 그리드 등) 없음

3. 디자인 값 출처

  • 색상/폰트/radius는 하드코딩 금지, frontend/src/styles/webTokens.css의 CSS 변수만 사용
  • 변수에 없는 새 값이면 Figma mulkko-style-guide 파일(fileKey: PpV1b4s9zsB1UHLGEtBQWP) Dev Mode 실측값 기준으로 추가
  • 새 값 추가 시 /dev/web-style-guide(frontend/src/components/WebStyleGuide/)에도 같이 반영

4. 파일 위치

  • 화면 컴포넌트: frontend/src/pages/<기능별폴더>/Xxx.tsx
  • CSS: frontend/src/styles/xxx.module.css

5. 라우팅

  • App.tsx에 등록할 경로 (예: /mypage, /signup/complete)

6. 백엔드 연동 여부

  • 필요한 API 있으면 엔드포인트 + 파일 위치까지 명시
    • 기존 것 재사용: 예) POST /api/auth/signup (backend/api/auth.py)
    • 신규 필요: 어느 파일에 추가할지 예상 위치 (예: backend/api/xxx.py 신설 또는 기존 파일에 추가)
  • 응답 형식은 {success, data} / {success, error:{message, code}} 고정

7. 예외 상태

  • 로딩 중 / 에러 / 빈 데이터일 때 어떻게 보여줄지
