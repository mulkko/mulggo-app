전처리는 어떻게 했나 기업마당

  • 텍스트: _x000D_/NBSP/zero-width space/BOM 제거, CRLF→LF, 연속 공백 정리
  • bsns_sumry_cn(사업개요): HTML 태그 제거 후 다시 정규화
  • URL 필드는 공백만 정리, 값 자체는 안 바꿈
  • 중복은 pblanc_id 기준, updt_pnttm 최신 우선
  • 신청기간: "2026-08-24 ~ 2026-09-11" 형식 파싱, "예산소진시까지"/"상시" 등은 원문 보존하고 날짜는 안 지어냄
  • [2026-09-07 수정] 문의처(contact): 원본 raw CSV에 있던 refrncNm(담당기관+연락처, 1589건 중 1588건 값 존재)을 크롤러가 DB에 저장 안 하고 빠뜨리고 있던 걸 발견 — 크롤러 INSERT 컬럼에 추가해서 이제 채워짐
검증 상태 실제 PostgreSQL 자격증명이 없어 합성 데이터로 로직만 검증했다(아래 값 전부 테스트 입력). 실 DB 연결 후 첫 실행 결과는 다시 확인 필요.
