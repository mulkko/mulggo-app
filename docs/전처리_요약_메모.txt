최종적으로 announcements 테이블에 들어가는 값 (예시)
===================================

※ 실제 DB로 돌린 게 아니라, 파이프라인 코드에 예시 공고 하나씩 넣고
   9단계를 다 통과시켜서 나온 값입니다. 형식/로직 검증용이고, 진짜
   운영 데이터가 아닙니다. (실제 DB 연결 전이라 진짜 값은 아직 없음)

--- 기업마당 예시 ---
원본: "2026년 부산 수출 스타기업 점프업 지원사업 수혜기업 모집공고"

  제목(title)          = 2026년 부산 수출 스타기업 점프업 지원사업 수혜기업 모집공고
  내용(content)        = 부산지역 중소기업의 수출역량별 맞춤형 지원사업 (HTML 태그 제거됨)
  게시기관(host_org_name)      = (재)부산테크노파크   ← 수행기관
  소관기관(supervising_org)    = 부산광역시            ← 소관기관
  분류(category)       = 수출 > 해외진출
  대상(target_summary) = 중소기업
  연령/업력 조건        = 둘 다 빈값 (원본에 아예 없음, 억지로 안 채움)
  신청기간             = 2026-09-01 ~ 2026-11-30
  신청방법             = 온라인 접수(홈페이지)
  지역(regions)        = [] (빈 배열) + region_status = "지역제한 없음으로 추정"
  업종(ksic_status)    = "특정불가" (내용만으로는 업종코드 판정 불가 → 코드 없이 저장)
  문의처(contact)      = 부산테크노파크 글로벌사업팀 051-320-3555, yul@btp.or.kr
                         (2026-09-07 수정 후: refrnc_nm 원본값 그대로 들어감)

--- 창업진흥원 예시 ---
원본: "2026년 예비창업패키지 청년창업사관학교 모집공고"

  제목(title)          = 2026년 예비창업패키지 청년창업사관학교 모집공고
  내용(content)        = 예비창업자 및 3년 미만 창업기업 대상 사업화 자금 지원
  게시기관(host_org_name)      = 중소벤처기업부   ← 공고 게시기관명
  소관기관(supervising_org)    = 창업진흥원       ← 주관기관
  담당부서(contact)    = 창업기획팀
  분류(category)       = 사업화
  대상(target_summary) = 예비창업자, 창업 3년 이내 기업
  대상연령(target_age_groups) = ["만 20세 이상 ~ 만 39세 이하"]  (배열로 감싼 상태)
  업력조건(business_age_condition) = 예비창업자~3년미만
  신청기간             = 2026-09-01 ~ 2026-10-31
  신청방법             = 온라인 접수(K-Startup 누리집)
  지역(regions)        = [서울특별시, 부산광역시]  ← 원본 구조화 필드 그대로라 신뢰도 높음
  업종(ksic_status)    = "업종무관(기본값)"  ← 판정 자체를 안 하고 무조건 이 값 (팀 결정)

  * 창업진흥원은 지역이 구조화 데이터라 항상 나옴 / 기업마당은 본문에서
    추론해야 해서 안 나오는 경우가 많음(위 예시도 빈 배열)
  * 기업마당 문의처는 2026-09-07 수정 후 채워짐(단, 수정 전 수집분은 여전히
    빈값) / 창업진흥원은 담당부서명이 원래부터 그대로 들어와서 채워짐
  * 두 소스 다 raw_bizinfo_id 또는 raw_kstartup_id 둘 중 하나만 채워지고
