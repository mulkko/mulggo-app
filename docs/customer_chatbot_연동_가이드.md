# 고객센터 챗봇 API 연동 가이드 (인수인계용, 2026-09-09)

> 이 문서는 코드를 잘 몰라도 순서대로 따라 하면 되도록 만들었습니다.
> Claude Code(AI)한테 시킬 말과, 결과를 눈으로 확인하는 방법까지 그대로 적어뒀습니다.

## 지금 뭐가 있고, 뭘 해야 하나요?

- `backend/customer_chatbot/` 폴더에 챗봇 **로직 자체는 이미 완성돼서** 들어와 있습니다.
  (질문 넣으면 답변 만들어주는 함수가 이미 있음 — 이 폴더 안 파일은 안 고쳐도 됩니다.)
- 근데 이 로직을 **웹 API로 감싸는 작업**이 아직 안 됐습니다. 그래서 지금은 프론트엔드
  화면에서 이 챗봇을 호출할 방법이 없습니다. 이 문서는 그 "감싸는 작업"을 하는 방법입니다.

## 시작하기 전에

1. 이 프로젝트 폴더(`mulkko`)에서 Claude Code를 켭니다.
2. 아래 1단계 프롬프트를 **그대로 복사**해서 붙여넣고 실행(Enter)합니다.
   문구를 바꾸거나 요약하지 말고 그대로 주는 게 제일 안전합니다.

## 1단계 — Claude Code에게 이 프롬프트를 그대로 주세요

```
backend/customer_chatbot/customer_service_bot.py 파일 맨 위 "TA 전달용 요약" 주석을 읽고,
call_llm_for_customer_support 함수를 호출하는 FastAPI 엔드포인트를 만들어줘.

- 참고 패턴: backend/api/test_ocr.py (이미 있는 간단한 엔드포인트 예시)
- 응답 형식은 CLAUDE.md의 API 응답 포맷({"success": true, "data": ...}) 그대로 맞춰줘
- 새 라우터 파일은 backend/api/ 안에 만들고, backend/main.py에도 등록해줘
- 다 되면 서버 켜서 실제로 질문 하나 보내서 답변 오는지 확인해줘
```

Claude Code가 파일을 만들고 고치는 동안, 뭘 하는지 다 몰라도 됩니다. 끝났다고 하면 2단계로 갑니다.

## 2단계 — 진짜 됐는지 눈으로 확인하기 (코드 안 읽어도 됨)

1. 터미널에서 서버를 켭니다 (Claude Code한테 "서버 켜줘"라고 하면 됩니다).
2. 브라우저에서 아래 주소를 엽니다:
   ```
   http://localhost:8000/docs
   ```
   FastAPI가 자동으로 만들어주는 테스트 화면입니다.
3. 방금 만든 엔드포인트(고객센터/챗봇 관련 이름)를 찾아서 클릭 → **"Try it out"** 버튼 클릭
4. 질문 칸에 아무 질문이나 입력 (예: "회원가입은 어떻게 하나요?") → **"Execute"** 클릭
5. 화면 아래 응답에 이런 모양이 나오면 성공입니다:
   ```json
   {
     "success": true,
     "data": {
       "answer": "...",
       "needs_human_support": false
     }
   }
   ```

이 화면이 안 나오거나 에러가 뜨면 실패입니다 — 3단계로 가세요.

## 3단계 — 안 될 때

1. 에러 메시지를 **그대로 복사**해서 Claude Code한테 붙여넣고 "이 에러 왜 나?"라고 물어보세요.
   에러 내용을 요약하거나 다시 쓰지 말고 원문 그대로 주는 게 훨씬 빨리 해결됩니다.
2. 그래도 안 풀리면, 에러 메시지 + `http://localhost:8000/docs` 화면 스크린샷을 캡처해서
   원 담당자에게 그대로 보내주세요. 코드를 몰라도 이 두 개만 있으면 진단할 수 있습니다.

## 4단계 — 다 됐으면 (여기서 끝이 아닙니다!)

`CLAUDE.md`에 있는 규칙: **커밋 + 푸시로 끝나는 게 아니라, PR(Pull Request)까지 열어야 완료**입니다.

1. Claude Code한테 "지금까지 한 거 커밋하고 푸시해줘, PR 링크도 만들어줘"라고 요청하세요.
2. 만들어준 PR 링크를 열어서 실제로 "Create pull request" 버튼까지 눌러야 진짜 끝입니다.

## 건드리지 않아도 되는 것 (미리 알아두면 헷갈림 방지)

- `.env` 파일 — 이미 필요한 키(`OPENAI_API_KEY`)가 들어있습니다. 손댈 필요 없습니다.
- `backend/customer_chatbot/` 폴더 안의 로직 — 이미 완성된 상태로 온 것이라 안 고쳐도 됩니다.
  (이 폴더를 감싸는 새 파일만 `backend/api/`에 추가하는 게 이번 작업입니다.)
