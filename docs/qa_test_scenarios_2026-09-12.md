# QA 테스트 시나리오 (2026-09-12 기준)

> 자동화 테스트가 없는 프로젝트라(pytest/vitest 등 미설치 확인함) 사람이 직접
> 클릭해보며 확인하는 **수동 테스트 체크리스트**입니다. `frontend/dev/dev_links.html`에서
> 구현율이 어느 정도 채워진 화면들 위주로, 실제로 눌러봐야 아는 흐름만 담았습니다.
> 화면이 아직 없거나(진단 결과 화면, 관리자 통합반영 상세 등) 팀 내 재작업 중인
> 항목(사업구체화 진단 ↔ 업종코드 매칭 연결)은 이번 체크리스트에서 뺐습니다 —
> 그쪽 작업 끝나면 별도 시나리오로 추가하는 걸 추천해요.
>
> 테스트할 때 체크: `- [ ]` → `- [x]`로 바꾸면서 진행하시면 됩니다. 실패하면 항목
> 옆에 `(실패: 무슨 증상)`을 남겨두세요.

## 사전 준비
- [ ] 프론트(`npm run dev`, :5173) / 백엔드(`python -m backend.main`, :8000) 둘 다 실행 중인지 확인
- [ ] `.env`의 `DEV_AUTO_LOGIN_EMAIL`이 설정돼 있으면, 접속하자마자 그 계정으로 자동 로그인됨 — 다른 계정으로 테스트하려면 먼저 로그아웃부터

## 4. 프로필 수정 (`/mypage/edit`) — 2026-09-11 작업분 포함

| 절차 | 기대 결과 |
|---|---|
| ① 예비창업자 계정으로 진입 | 상호명/업력/직원수/연매출/기업 규모 입력창 전부 숨겨지고, 안내 문구만 보임 |
| ② 예비창업자 계정에서 "기업유형" 항목 | "예비창업자"라고 읽기전용으로 표시(select 아님) |
| ③ 사업자등록증이 있는(기존사업자) 계정으로 진입 | "기업유형"에 "개인" 또는 "법인" 표시, 업력/직원수/연매출/기업 규모 입력창 보임 |
| ④ ③ 계정에서 아직 값 안 넣은 필드(업종 설명/사업장 지역/대표자 연령대) | **더미값 아니라 진짜 빈 칸/"미선택"**으로 보이는지(2026-09-11 버그 수정 확인 포인트) |
| ⑤ 사업자등록증 등록 시 업종(KSIC) 검색해서 확정 | 저장 후 "업종 설명(원문)" 아래에 "선택한 업종(KSIC): OO (코드)"가 읽기전용으로 뜨는지 |
| ⑥ "기업 규모" 드롭다운에서 "소상공인" 선택 후 저장 → 새로고침 | 선택한 값 그대로 유지되는지 |

| ⑧ 이름 수정 후 저장 → `/mypage`로 이동해서 상단 프로필 카드 확인 | 바뀐 이름이 바로 보이는지 |
