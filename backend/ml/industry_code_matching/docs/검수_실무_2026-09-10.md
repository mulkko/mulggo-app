# 골든셋 검수 — 딱 이대로만 하면 됨

---

## A. 네가 만지는 파일 — **단 1개**

### `business_matching/골든셋_검수.xlsx`

엑셀로 열어서 오른쪽 끝 컬럼만 채운다. 왼쪽 컬럼(seed, llm_why 등)은 **읽기만**.

| 채울 컬럼 | 언제 | 값 |
|---|---|---|
| **`사람_확정_primary`** | LLM 코드가 **틀렸을 때만** | 올바른 6자리 (예: `552303`) |
| `사람_확정_secondary` | 복합 사례에 진짜 부가 업종이 있을 때만 | 6자리 |
| `사람_확정_note` | 이 사례를 버릴 때 | `제외` |
| **`사람_검수완료`** | **검수한 모든 행** | `Y` |

### 판단 규칙

| 상황 | `사람_확정_primary` | `사람_검수완료` |
|---|---|---|
| LLM 코드 맞음 | (비움) | `Y` |
| LLM 코드 틀림 | 올바른 6자리 | `Y` |
| 사례 자체가 이상함 | (비움) | `사람_확정_note` 에 `제외` |
| **category = "정보부족" 행** | **아무것도 안 함** (자동 교체됨) | (안 함) |

### 순서

1. **맨 위 ~35건** (auto_check ≠ OK) — 어려운 것. `business_code_master_v1.csv` 에서 직접 코드 확인.
2. **나머지 144건** (auto_check = OK) — `llm_why` 읽고 맞으면 `Y`. 대부분 맞음.
3. **정보부족 20건** — 건너뜀.
4. **저장 (xlsx 그대로, 다른 이름 X)**

소요: 2.5~4시간. 나눠서 해도 됨.

## B. 코드 찾을 때 참고하는 파일 — **읽기 전용**

### `data/processed/business_code_master_v1.csv`

국세청 업종코드 1,612개 사전. 엑셀로 같이 열어놓고 `business_name` / `definition` / `include_activities` 로 검색해서 올바른 6자리를 찾는다.

## C. 검수 끝나면 — 명령 3개

패키지 폴더에서:

```bash
# 1. 검수 파일 -> 정답지  (골든셋_검수.xlsx 자동으로 읽음, 정보부족은 자동 교체)
python business_matching/finalize_gold.py

# 2. 파이프라인 채점  (~$1.5. 돈 부족하면 뒤에 --limit 100)
python business_matching/eval_pipeline.py --gold business_matching/gold_set_v3.csv

# 3. 자동확정 게이트 표  (무료)
python business_matching/ensemble_gate.py --gold business_matching/gold_set_v3.csv
```

- 2번 출력 = **최종 Top-1 / Recall@3 / MRR** → 발표에 씀
- 3번 출력 = 자동확정 A~E 트레이드오프 표 (커버 vs 정확도). 원하는 지점 골라서 `23_..._v3.py` 의 `AUTO_CONFIDENCE` 만 조정 (선택)

**여기까지 하면 계획서 ①~⑦ 끝.**
