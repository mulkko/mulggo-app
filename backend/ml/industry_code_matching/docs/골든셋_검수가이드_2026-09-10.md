# 골든셋 검수 가이드 — 사용자 작업

목표: `gold_draft_v1.csv` 179건의 **정답 업종코드를 사람이 승인** (계획서 §10.2). LLM 초안은 있음, 최종 판단만 하면 됨.

---

## 어떤 파일을 여나

`business_matching/골든셋_검수.xlsx` — 엑셀로 열기. **플래그(어려운) 케이스가 위쪽에 정렬돼 있음.** 헤더 고정됨.

| 컬럼 | |
|---|---|
| `seed` / `problem_or_opportunity` / `solution_approach` | Q1 / Q3 / Q4 (사례 내용) |
| `is_offline_store` | Q5 (true/false) |
| `llm_expected_primary` (+ `_name`) | LLM이 찍은 정답코드 |
| `llm_why` | LLM 근거 |
| `auto_check` | `OK` = bge-m3 검색 상위 20에 그 코드 있음 / `검색밖`·`검색NN위` = 없거나 깊음 |
| **`사람_확정_primary`** | ← **여기 채움** (LLM 코드가 맞으면 비워둬도 됨. 틀리면 올바른 6자리) |
| `사람_확정_secondary` | 복합 사례의 부가 업종 (있으면) |
| `사람_확정_note` | `제외`/`버림` 쓰면 그 행 폐기됨. 메모 남겨도 됨 |
| **`사람_검수완료`** | ← 검수 끝난 행에 `Y` |

## 순서 (빠른 길)

1. **`auto_check == OK` 144건 먼저** — LLM 코드가 검색 상위에 있어서 대개 맞음.
   - `llm_why` 읽고 `seed`/`solution` 과 맞으면 → `사람_확정_primary` 비워두고 `사람_검수완료 = Y`
   - 틀리면 → 올바른 6자리를 `사람_확정_primary` 에, `사람_검수완료 = Y`
   - 국세청 업종코드 찾기: `data/processed/business_code_master_v1.csv` 에서 `business_name`·`definition` 검색
2. **`auto_check != OK` 35건** (유사경계 15 / 명확단일 11 / 복합 6 / 구어체 3) — 신중히.
   검색이 못 잡은 케이스라 LLM 코드도 의심. `business_code_master_v1.csv` 에서 직접 찾아 확정.
3. **"정보부족" 20건** (`gold_none_v1.csv` 로 이미 교체됨) — 검수 불필요. 정답 = NONE(공백).
   `gold_set_v3_review.csv` 에 이미 들어가 있음.

## 시간

144건 × 30초~1분 + 35건 × 2~3분 ≈ **2.5~4시간**. 카테고리별로 나눠서 해도 됨.

## 끝나면

```bash
python business_matching/finalize_gold.py          # --auto 없이!  -> gold_set_v3.csv
python business_matching/eval_pipeline.py --gold business_matching/gold_set_v3.csv   # ~$1.5
python business_matching/ensemble_gate.py --gold business_matching/gold_set_v3.csv   # 무료
```
→ 확정 성능 숫자 (지금 것은 "LLM 초안 + 자동검증" 기준의 잠정치).
