# 1. 임베딩 모델 비교 (개정 계획서 §6.4 "평가 후 선택")

**조건**: 원문(Q1+Q3+Q4) → 임베딩 검색만. LLM 미사용. 사람 검수 골든셋 158건(NONE 제외). 각 모델로 14,627 문서 재색인(GPU) 후 측정. **크레딧 0.**

| 모델 | Top-1 | Recall@3 | Recall@10 | Recall@20 | MRR@20 |
|---|---|---|---|---|---|
| KURE-v1 (한국어 retrieval 특화) | **41.8** | 58.2 | **74.1** | **79.7** | **0.52** |
| bge-m3-ko (BGE-M3 한국어 파인튜닝) | 40.5 | **59.5** | 72.2 | 76.6 | 0.52 |
| **BGE-M3** (채택) | 33.5 | 51.9 | 70.3 | 77.8 | 0.46 |
| ko-sroberta-multitask (한국어 클래식) | 28.5 | 49.4 | 63.9 | 74.1 | 0.41 |

- 한국어 튜닝 버전(KURE-v1, bge-m3-ko)이 원문 검색에서 BGE-M3보다 ~8pt 우위.
- 그러나 **전체 파이프라인(LLM 재판정 포함)으로는 차이가 사라짐** — 아래 §3.

# 2. 방법 단계별 비교 (개정 계획서 §10.5)

**조건**: 사람 검수 골든셋 90건(NONE 제외 80건). A~C 는 LLM 0.

| 방식 | Top-1 | Recall@3 |
|---|---|---|
| A. 키워드만 (토큰 매칭) | 21.2 | 40.0 |
| B. 임베딩만 (BGE-M3) | 43.8 | 58.8 |
| C. 하이브리드 (키워드+임베딩 RRF 병합) | 31.2 | 57.5 |
| D. + LLM 구조화 | *(예산상 생략)* | |
| **E. + LLM 재판정 (전체 파이프라인)** | **70.0** | **82.5** |

- 키워드 단독은 약함 (KSIC 세세분류명이 반직관적: "밀가루 제조" → 곡물 제분업).
- 단순 RRF 하이브리드는 오히려 Top-1 하락 — 약한 키워드 결과가 상위를 오염. (파이프라인은 채널 분리로 이를 방지.)
- **LLM 구조화 + 재판정이 핵심 도약: 44% → 70% (+26pt).**

# 3. 임베딩 모델 — 전체 파이프라인 실측 (BGE-M3 vs KURE-v1)

**조건**: 같은 90건, 전체 파이프라인(구조화 + 검색 + 재판정 + 3상태). KURE-v1 재평가에 ~$1.

| 지표 | BGE-M3 | KURE-v1 |
|---|---|---|
| **Top-1** | **70.0** | 68.8 |
| Recall@3 | 82.5 | 81.2 |
| MRR (pool 내 정답 순위) | 0.57 | 0.63 |
| 자동확정 비중 | 26% | 46% |
| 자동확정 정확도 | **97%** | 86.5% |
| 정보부족 감지 | **100%** | 90% |

- Top-1 68.8 vs 70.0 = n=90 신뢰구간(±약 10pt) 안 → **차이 없음.**
- KURE-v1 이 원문 검색에서 앞섰지만 LLM 재판정이 BGE-M3 의 약간 뒤진 검색을 복구 (정답이 pool 상위 20에 들어오는 비율은 둘 다 ~77~80%).
- KURE-v1 은 자동확정 커버가 넓으나(46%) 그 버킷 정확도가 목표(90%) 미달(86.5%). BGE-M3 은 좁지만(26%) 97%.

# 4. 결정

| 항목 | 선택 | 근거 |
|---|---|---|
| 임베딩 | **BGE-M3** | 전체 성능 KURE-v1 과 동점, 자동확정 버킷이 90% 목표 상회, 이미 검증·문서화 |
| 검색 방식 | **키워드 + 임베딩 하이브리드 (채널 분리)** | §2: 임베딩이 키워드 압도, 채널 분리로 하이브리드 손실 방지 |
| 재판정 | **LLM (gpt-5-mini)** | §2: +26pt. 파이프라인의 핵심 |
