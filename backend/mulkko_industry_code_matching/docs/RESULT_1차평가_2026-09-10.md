## 2. 발견 (⑦의 핵심)

### 발견 A — 파이프라인 자체는 문헌 범위에 있다

63.4% Top-1 (이전 67%와 동급). 사람 코더 간 세분류 일치가 51~77%인 걸 감안하면 **6자리에서 63%는 낮지 않다**. 유사경계 47%가 전체를 끌어내림 (의도된 난이도).

### 발견 B — 3상태 게이팅이 문헌 운영점에 못 미친다

| | 실측 | 목표 |
|---|---|---|
| 추천_가능 비중 | **88.6%** | ~55% |
| 추천_가능 버킷 정확도 | **65%** | ≥90% |

시스템이 "자신 있다"를 너무 자주 말한다. high 버킷조차 73%라 **90% 자동확정 기준을 현 구조로는 못 맞춘다.**

### 발견 C — "정보 추가 필요"가 작동하지 않는다

NONE(분류 불가) 입력 18건 중 **0건**을 잡았다 (13건 추천_가능, 5건 확인필요). "product_service가 비었나" 규칙은 LLM이 항상 뭔가 채워 넣어서 절대 발동 안 됨.

## 2b. 튜닝 후 재평가 (2026-09-10 오후, 69건 층화)

튜닝 3가지 적용: 게이트 컷(`high & 선택후보 pool순위 ≤2`), `classifiable` 신호, seed 상한 400.

| 지표 | 1차 (144) | 2차 튜닝 (69) | 문헌 |
|---|---|---|---|
| Top-1 | 63.4% | 62.7% | 65~80% |
| Recall@3 | 78.9% | 81.4% | |
| **추천_가능 비중** | 88.6% | **52.5%** | ~55% → **✅ 해결** |
| **추천_가능 정확도** | 65% | **64.5%** | ≥90% → **❌ 미해결** |
| 정보_추가_필요 감지 | 0/18 | 0/10 | → **❌ (원인은 골든셋)** |

### 왜 정확도가 안 오르나

`39_calibrate_gate.py` 는 1차 데이터에서 `high & 순위≤2` → 90.9% 를 봤지만, 2차(다른 케이스)에선 64.5%. **소표본 과적합.**
근본 원인: **모델(gpt-5-mini)의 재판정이 "확신에 찬 오답"을 내는 비율이 ~35%.** 확신 있는 오답은 확신 있는 정답과 신호가 같아서, 신뢰도·순위 게이트로 걸러지지 않는다.
"추천_가능인데 오답" 11건 분석: 대부분 세분류 인접 오답(미용업 vs 두발미용업, 공구소매 vs 철물소매). 모델이 rank 1~3을 high로 골랐는데 옆칸.

### 왜 정보_추가_필요가 0인가 (골든셋 문제)

"정보부족" 10건을 열어보니 **실제로는 막연하지 않다.** 초안 생성 LLM이 "AI 영어회화 앱+구독", "카페 배달 플랫폼+수수료", "기업 워크숍 B2B" 같은 **분류 가능한 복합/경계 사례**를 "정보부족"으로 잘못 라벨링했다. `classifiable=yes` 가 맞다.
→ 파이프라인 버그 아님. **`36_build_gold_draft.py` 의 "정보부족" 생성 프롬프트가 약함.** 진짜 막연한 사례는 합성이 어려움 — 사람 검수 때 이 카테고리를 직접 채우거나, 생성 프롬프트를 "비전·팀소개만, 품목·수익 언급 금지"로 강화.

### 도달 가능한 운영점 (현 모델 기준)

| 컷 | 커버 | 정확도 |
|---|---|---|
| high & 순위≤1 | ~37% | ~73% |
| high & 순위≤2 (현재) | ~50% | ~65% |

**90%는 현 구조로 불가.** 올리려면: (a) gpt-5-mini → gpt-5 full, (b) 앙상블 신호 — 원문검색 1위와 LLM 선택이 일치할 때만 자동확정, (c) 2회 독립 재판정 투표.

## 3. 정직한 결론

1. **파이프라인 Top-1 ~63%** 은 안정적이고 문헌 범위 근처다. 이건 진짜 숫자다.
2. **자동확정(추천_가능) 90% 정확도는 현 모델(gpt-5-mini)로 불가.** 커버는 55%로 맞췄지만 정확도는 ~65%. 모델이 "확신에 찬 오답"을 ~35% 내고, 이건 신뢰도 게이트로 못 거른다.
   - 현실적 운영점: **high & 순위≤1 → 커버 37% / 정확도 73%** 정도.
   - 90% 원하면: 원문검색↔LLM선택 일치 게이트(앙상블), 또는 gpt-5 full, 또는 2회 투표.
3. **"정보부족" 골든셋 라벨이 잘못됐다.** 초안이 분류 가능한 사례를 그 카테고리로 넣었음. 파이프라인 버그 아님.
4. **다음 라운드 (사용자 검수 + 방법 선택 필요):**
   - `gold_draft_v1.csv` 179건 사람 검수 → `37_finalize_gold.py` (특히 "정보부족" 재작성)
   - 90% 자동확정을 포기하고 "73%@37% 자동 + 나머지 확인질문" 으로 갈지, 앙상블/모델업그레이드로 갈지 결정
   - 앙상블 게이트(원문검색 1위 == LLM 선택)는 무료로 시험 가능 → 다음 세션
