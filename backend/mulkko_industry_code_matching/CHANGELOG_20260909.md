## 수정 내용

### 1. 사업 역할(business_role) 확정 강화 — `ACTIVITY_SYSTEM`
- `[역할 확정 규칙]` 블록: 직접 제조=제조 / 떼다 팔면 도소매 / 연결 수수료면 중개 /
  매장 조리면 음식점 / 플랫폼·AI는 그 자체가 상품 아니면 역할 아님.
- `[제조로 착각하기 쉬운 도매·소매·서비스]` 카브아웃: 판매 전 손질·선별·소분·재포장은
  제조가 아님 / 안경원(검안·조제·판매)은 소매 / 완제품 설치·조립만은 도소매.
  (구조화 LLM이 "손질·조제·조립" 단어에 제조·가공을 과잉 발동하던 문제 교정)

### 2. Role-aware 후보 필터 — `role_fit()`, `ROLE_SECTION_CONFLICT/PREFER`, `build_candidate_pool()`
- 후보 업종의 대분류가 역할과 명백히 상충하면(소매인데 제조업 등) 검색 순위를 12칸 뒤로,
  역할에 부합하면 6칸 앞으로.
- **완전 배제가 아니라 순위 조정** — 구조화가 역할을 오판해도 상충 후보가 재판정 창에는 남아
  LLM이 되돌릴 수 있음.

### 3. 검색 채널 분리 — `_search_channel()`, `vector_search_multi()`
- BASE 채널(name/hier/ksic/desc/def) 상위 25개는 **반드시 유지**.
- EXAMPLE 채널(example/xref) 상위 12개는 **추가만** — BASE 후보를 밀어내지 못함.
- 제조업 해설서 예시가 검색을 오염시켜 gold_v1 정확도를 95→83%로 떨어뜨리던 문제 해결.

### 4. 해설서 `<제외>` 규칙 반영
- `25_prepare_business_code_docs.py`: `xref` 문서유형 신설.
  `<제외>`에서 "이 활동은 A가 아니라 B로 간다"의 B 코드에 그 활동을 양성 신호로 색인 (2,859개).
  `is_clean_phrase()` 노이즈 필터 추가.
- `23_match_business_code_v3.py`: `load_exclusion_notes()` 신설.
  재판정 프롬프트가 후보별로 "역할 적합성: 부합/중립/상충" + "이 코드가 아닌 활동(해설서 제외)"을 표시.

### 5. 재판정 프롬프트 — `RERANK_SYSTEM`
- 판정 순서를 명시: **1순위 역할 → 2 제품/서비스 일치 → 3 포함 예시 → 4 제외 규칙 위반 → 5 KSIC → 6 계층.**
- 역할 상충 후보는 원칙적으로 탈락하되, 활동 설명이 명백히 그 후보를 가리키면
  "역할 라벨이 잘못 붙었다"고 보고 선택 가능(구조화 오판 복구용).
- 후보 목록 밖 코드 생성 금지(기존 유지).

### 6. 신뢰도 가드 데이터 재설정 — `compute_confidence()`
- 29번 calibration(gold_v2 240건 실측) 기반:
  후보 순위 임계값 6위→4위, 한쪽 검색만이면 항상 하향, margin<0.06 하향 추가,
  (6위+ & 한쪽만) = low 확정.
