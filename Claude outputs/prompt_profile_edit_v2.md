[작업 배경]
17-1 프로필 수정 화면(`pages/mypage/ProfileEdit.tsx`, 라우트 `/mypage/edit`)을 건드리지 않고, **완전히 별도의 새 화면**을 하나 더 만든다. 다른 담당자가 이 화면을 보고 백엔드 연동을 새로 붙일 예정이라, 프론트(레이아웃/입력 필드 구성)만 정확히 맞추면 됨 — 이번 라운드는 데이터 연동(GET/PUT) 없이 정적 폼으로만 만들어도 됨(값은 프로토타입처럼 하드코딩된 초기값 넣어도 되고 비워도 됨, 알아서 판단).

**절대 지킬 것**: `ProfileEdit.tsx`, `MyPage.tsx`, 기존 라우트 `/mypage/edit`, 관련 CSS(`styles/profileEdit.module.css` 등 기존 파일)는 전혀 수정하지 않는다. 새 파일만 추가한다 — 예: `pages/mypage/ProfileEditV2.tsx` + `styles/profileEditV2.module.css`(파일명은 기존 컨벤션에 맞게 네가 정해도 됨). `App.tsx`에 새 라우트 `/edit-v2` 추가(기존 `/mypage/edit` 라우트는 그대로 둠).

이 화면은 아래 [실측 디자인 값]에 있는 기존 프로토타입의 "프로필 수정" 화면 스타일(인풋/셀렉트/구분선/저장버튼 등)을 그대로 따르되, **항목 구성 자체는 프로토타입과 다르다** — 아래 [항목 구성]대로 재배치할 것. 모바일 화면에서만 보여지는 페이지라, 프로토타입에 있는 디자인 중 무시해도 되는 부분(예: 데스크톱 전용 여백 등)이 있으면 적절히 생략해도 됨.

[항목 구성] — 프로토타입엔 없는, 이번에 새로 정하는 배치

1) 기본 정보 (그대로 유지, 기존 `ProfileEdit.tsx`와 동일 항목)
   - 이름 (편집 가능)
   - 이메일 (읍기전용, Inter 폰트 `#8B8D93`)

2) 사업자 정보 — `biz_registration_docs` 테이블 기준, 개인/법인 전용 필드 구분 없이 전부 순서대로 나열(아래 순서 그대로):
   - 사업자등록증 (선택) — 위 업로드 박스
   - 사업자번호 (`biz_no`)
   - 법인등록번호 (`corp_no`, 법인)
   - 상호명/법인명
   - 대표자명(성명)
   - 개업연월일
   - 생년월일 (개인)
   - 사업장소재지
   - 본점소재지 (법인)
   - 업태/종목

   ⚠️ 이 섹션의 "상호명/법인명"은 아래 3)의 "상호명"과 이름이 비슷해 보이지만 **다른 테이블의 다른 값**이니, state 변수명을 겹치지 않게 분리해줘(예: `bizDocCompanyName` vs `profileCompanyName` 식, 정확한 이름은 네가 컨벤션에 맞게 정해도 됨). 데이터 연동은 이번엔 안 해도 되고, 하고 싶으면 해도 됨(테이블 컬럼은 위 라벨에 병기된 영문명 그대로).

3) 기타 정보 — **새로 추가하는 섹션, "사업자 정보"와 같은 위계(같은 소제목 스타일, 구분선으로 위 섹션과 분리)**. `business_profiles` 테이블 기준, 아래 10개 항목만(기존 `ProfileEdit.tsx`에 있던 "기업유형" select는 이 화면엔 포함하지 않음 — "사업자구분"이 그 역할을 대체):
   - 사용자 유형 — 자유 텍스트 인풋
   - 사업자구분 — **개인/법인 2개 옵션 셀렉트**(사업자등록증을 등록하지 않은 사용자가 직접 선택하는 값, 위 2)와는 별개의 테이블/컬럼)
   - 상호명 — 자유 텍스트 인풋 (위 2)의 "상호명/법인명"과는 별개 값)
   - 업종 설명(원문) — 자유 텍스트 인풋
   - 사업장 지역 — 셀렉트(마포구(선택)/서대문구/은평구, 기존 ProfileEdit과 동일 옵션)
   - 업력(개월) / 직원수 — 한 줄에 두 칸(위 두 칸 레이아웃 재사용)
   - 연매출 — 자유 텍스트/숫자 인풋
   - 대표자 연령대 — 셀렉트(20대/30대(선택)/40대/50대 이상, 기존 ProfileEdit과 동일 옵션)
   - 자격/우대 — 자유 텍스트 인풋

   한 줄에 두 칸 배치는 "업력(개월)/직원수" 외에도 짧은 필드끼리(예: 사용자 유형+사업자구분, 대표자 연령대+자격/우대 등) 자연스럽게 묶어도 됨 — 정확한 배치는 네가 보기 좋게 판단해서 정해도 됨.
