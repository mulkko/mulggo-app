[작업 배경]
FAB(문의하기 페이지 우측 하단 챗봇 버튼) 디자인이 아직 프로토타입과 안 맞음. 방금 시도한 "이미지 확대(scale)" 방식은 잘못된 방향이었다 — 되돌리고, 아래 방식으로 다시 맞춘다. 기능(클릭 시 이동)은 그대로 유지.

[레퍼런스]
프로토타입 파일: `docs/260912_2011_Mulkko Prototype (standalone).html`, grep 키 `is.cs`(두 번째 등장, 19번 문의하기 화면) 안의 FAB(`{{ showFab }}`) 블록 — 이미지·CSS 값을 이미 직접 디코딩/확인해서 실제로 지금 쓰는 `8_white.png`와 완전히 같은 원본 이미지를 그대로 쓰고 있었음(별도로 미리 잘라둔 원형 이미지가 아니었음). 즉 트릭이 있는 게 아니라 **단순하게** `width:100%; height:100%; object-fit:cover`로만 넣고 있었음 — 지금처럼 `transform:scale(1.4)` 같은 확대를 추가한 게 오히려 문제였다. 이 값으로 되돌릴 것:
```
width:100%; height:100%; object-fit:cover; display:block;
```
(scale/transform 등 확대 관련 스타일은 전부 제거)

[문제 1 — 버튼 둘레에 테두리처럼 보이는 색]
`.fab`에 실제 `border`나 `outline`이 들어가 있는지 다시 확인해서 있으면 제거. 그래도 남아있다면 `box-shadow`가 원인일 수 있음 — 지금 값(`0 10px 24px -6px rgba(21,50,140,.45), 0 4px 10px -2px rgba(21,50,140,.3)`)의 blur가 버튼 크기(56px)에 비해 커서 옅은 남색 테두리처럼 번져 보일 수 있으니, 그럴 땐 blur를 12~16px, opacity를 .2~.25 정도로 줄여서 "아래로 살짝 깔리는 그림자"처럼만 보이게 조정(수치는 화면 보면서 자연스럽게).

[문제 2 — 마스코트 이미지 하단이 살짝 잘려 보임]
`8_white.png` 원본 이미지 자체가 캐릭터의 둥근 몸통 아랫부분이 이미지 캔버스 경계에서 살짝 잘려 있어서(원본 파일 문제), 원형 버튼에 그대로 넣으면 하단에 흰색이 아닌 부분이 살짝 비침. 아래 둘 중 편한 방법으로 처리:
- (A, 추천) `.fab`에 흰색 배경(`background:#FFFFFF`)을 깔고, 이미지 크기를 100%가 아니라 78~85% 정도로 줄여서 버튼 중앙에 배치(`display:flex; align-items:center; justify-content:center`) — 이미지가 살짝 작아지면서 잘린 하단부가 보이는 영역 밖으로 빠지고, 나머지 여백은 깔끔한 흰 원으로 보임.
- (B) 이미지 자체를 살짝 위로 올려서(`object-position: center top` 등) 잘린 하단부가 버튼 밖으로 밀려나가게.

로컬 개발서버(`http://localhost:5173/support`)에서 눈으로 보면서, 첨부한 두 스크린샷(잘못된 예 / 원하는 예)과 비교해 맞춰줘 — 정확한 %/px 값은 화면 보면서 자연스럽게 조정해도 됨. (스크린샷 2장을 클로드 코드한테도 같이 보여주면 더 정확하게 맞출 수 있음.)
