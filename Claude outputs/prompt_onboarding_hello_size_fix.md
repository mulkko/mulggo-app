[작업 배경]
방금 온보딩 프롬프트(`prompt_onboarding_update.md`)에서 첫 화면(step 0, `onboard_hello.png`) 마스코트를 "좀 크게" 요청해서 92%로 키웠는데, 실제로 보니 원 안에서 캐릭터가 너무 꽉 차 보인다. 위치(중앙 정렬)는 좋으니 **크기만 줄인다.**

[수정 내용]
`Onboarding.tsx`에서 step 0에 `<Mascot src={onboardHello} />`를 렌더링할 때 넘기는 `size` 값을 92%에서 **78%** 정도로 낮춰줘(다른 step 기본값 82%보다도 살짝 작게). 예:
```tsx
<Mascot src={onboardHello} size="78%" />
```
78%가 여전히 커 보이거나 작아 보이면 75~80% 범위 안에서 미세 조정해도 됨 — 다른 step들(기본 82%)과 비교했을 때 비슷하거나 살짝 작은 정도가 목표.
